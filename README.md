# Komentář k zákonu č. 281/2002 Sb., o některých opatřeních souvisejících se zákazem bakteriologických (biologických) a toxinových zbraní a o změně živnostenského zákona

Otevřený komentář k zákonu o opatřeních souvisejících se zákazem bakteriologických (biologických) a toxinových zbraní — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zákaz biologických a toxinových zbraní, vysoce rizikové a rizikové biologické agens a toxiny, povolení, evidence a deklarace, zabezpečení, kontrola a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2002-00281_2022-02-01`.
